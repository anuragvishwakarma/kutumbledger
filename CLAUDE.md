# KutumbLedger Project Guidelines

- Next.js 15 with App Router and TypeScript
- Tailwind CSS for styling
- Supabase for backend/auth/database
- Route groups: (dashboard), (auth)
- Component patterns: form handling with useState, role-based navigation
- Utility patterns: export functionality in lib/export.ts
- Styling: responsive design with mobile-first approach
- Icons: emoji-based icons for visual consistency
- State management: useState for settings, forms, and data display
- File organization: features grouped by domain (transactions, family, helpers, etc.)
- Onboarding: Tutorial system for new users with automatic redirect and progress tracking
